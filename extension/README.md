# 받냥이 확장 (단독 설치 안내)

이 확장은 **받냥이 앱이 켜져 있어야** 동작합니다(브라우저에서 잡은 URL·쿠키를 받냥이 로컬 브리지 `127.0.0.1:47653`로 보냄). 확장만으로는 다운로드가 안 됩니다.

## 가장 쉬운 방법 — `받냥이-확장설치.bat` (소스 ZIP·깃 클론)
1. `받냥이-확장설치.bat` 더블클릭 → 크롬 확장 관리 화면이 열리고, 확장 폴더 주소가 복사된다.
2. [개발자 모드] 켜기 → [압축해제된 확장 프로그램 로드] → 폴더 창 주소칸에 Ctrl+V → Enter → [폴더 선택].
3. 저절로 뜨는 "연결 설정"에서 [연결하기] → 받냥이 창에서 [예].
- 소스에는 서명된 CRX가 없어서(서명키는 저장소에 안 올림) 이 방식이 기본이다. 확장 ID는 manifest의 key 덕분에 그대로다.

## 방법 A — 자동 설치 (서명된 CRX가 있는 개발자 배포판만, 관리자 권한 1회)
크롬/엣지에 정책으로 자동 설치됩니다.
1. `받냥이-확장설치.bat` 더블클릭 → UAC "예".
2. 크롬/엣지 완전 종료 후 다시 켜기 → 툴바에 받냥이 아이콘.
3. 토큰은 자동(managed 정책). 팝업이 "받냥이 연결됨 ✅"이면 끝.
- 되돌리기: `받냥이-확장제거.bat`.
- 필요한 파일: `build/downcat-ext.crx`(`npm run pack-crx`로 서명키와 함께 생성), `scripts/downcat-ext-policy.ps1`, (있으면) `config.json`.
- ⚠ 회사 도메인에 묶이지 않은 개인 Windows PC에서는 크롬이 스토어 밖 확장의 강제설치를 막을 수 있다 → 그땐 위의 쉬운 방법.

## 방법 B — 수동 로드 (권한 없이, 개발자모드)
1. 크롬 `chrome://extensions` (엣지 `edge://extensions`) → **개발자 모드** 켜기.
2. **"압축해제된 확장 프로그램 로드"** → 이 `extension` 폴더 선택.
3. 확장 옵션 → **[🔗 연결하기]** → 받냥이 창에서 **[예]**.
   - (예전 방식) 옵션의 "직접 토큰 넣기"에 `config.json`의 `bridgeToken` 붙여넣기.
