# 🐾 받냥이 (DownCat)

URL을 붙여넣으면 영상·이미지를 알아서 폴더로 정리해 받아주는 바탕화면 다운로더.
(hitomi_downloader의 핵심 기능을 내 컴퓨터용으로 다시 만든 것.)

## 어떻게 만능인가
스크래퍼를 직접 안 짜고, 검증된 두 도구를 감싼다:
- **yt-dlp** → 유튜브·틱톡·트위터 영상 등 영상 사이트 수백 개
- **gallery-dl** → 인스타·핀터레스트·픽시브·imgur·hitomi 등 이미지 갤러리 수백 개

`auto` 모드는 링크 도메인을 보고 둘 중 알맞은 도구로 넘긴다.

## 주요 기능
- **작업 카드**: 받은 썸네일·개수·용량·상태(완료/일부/실패/취소)를 카드로. 받는 중엔 속도·남은 시간도 보인다.
  영상만 받아도 ffmpeg로 한 장면을 뽑아 썸네일을 만들어 보여준다(`thumbs/` 폴더).
- **취소 / 다시 받기 / 폴더 열기 / 기록 지우기**: 카드 오른쪽 버튼 (지워도 받은 파일은 남는다).
- **여러 링크 한 번에 + 대기열**: 줄바꿈으로 여러 URL을 넣거나 링크를 창에 끌어다 놓으면 등록.
  동시에 받는 개수(기본 1개)만큼만 받고 나머지는 "대기 중"으로 줄을 선다.
- **클립보드 자동 추가**: 설정에서 켜면 링크를 복사만 해도 자동 등록.
- **색 라벨 · 정렬 · 검색**: 카드 색점으로 분류, 하단 바에서 정렬/검색/색 필터.
- **갤러리 탭**: 받은 사진·영상을 썸네일 격자로.
- **⚙ 설정**: 저장폴더, 유튜브 최대 화질, ffmpeg 설치, 인스타 스토리, 동시 다운로드 개수,
  최대 다운로드 속도, 완료 카드 자동 제거, 항상 위, 완료 알림.

## 실행
- **`받냥이.bat` 더블클릭** (또는 `npm start`)
- URL 붙여넣고 [다운로드]. 저장 폴더·화질 등은 ⚙ 설정에서 바꾼다.

## 🎁 처음 받는 사람은 (친구/새 컴퓨터)
1. 깃헙 **Releases**에서 `DownCat-…-windows.zip`(완성품)을 받아 아무 폴더에 압축 해제
2. `받냥이.bat` 더블클릭 — 끝. **아무것도 따로 깔 필요 없다**
   (도구가 없으면 켤 때 자동으로 받는다 — 아래 "다운로드 도구 자동 관리")
- ⚠️ 소스 코드 ZIP(Code→Download ZIP)은 개발자용 — 아래 "처음 한 번 준비"가 필요하다.

## 처음 한 번 준비 (소스로 시작할 때)
- [Node.js LTS](https://nodejs.org) 설치 → `받냥이.bat` 더블클릭. 처음 한 번은 실행 엔진(Electron)을 자동으로 깐다(1~3분).
  (직접 하려면 이 폴더에서 `npm install`)
- 끝. 도구(yt-dlp·gallery-dl·ffmpeg·aria2)는 받냥이를 켜면 `bin/`에 자동으로 깔린다.
- 테스트: `npm test` (가짜 도구·가짜 GitHub로 경우별 시험 + 도구가 있으면 실제 도구로 한글 경로 확인)

## 🔧 다운로드 도구 자동 관리 (Windows)
| 도구 | 받는 곳 | 원본 확인(해시) | 업데이트 확인 |
|---|---|---|---|
| yt-dlp | yt-dlp/yt-dlp 최신 릴리스 | 릴리스의 `SHA2-256SUMS` (+ GitHub 해시) | 하루 한 번 |
| gallery-dl | gdl-org/builds (공식 빌드) | GitHub가 계산한 파일 해시 | 하루 한 번 |
| ffmpeg | yt-dlp/FFmpeg-Builds (지금 쓰던 yt-dlp용 빌드) | 릴리스의 `checksums.sha256` | 30일에 한 번, 빌드가 바뀌었을 때만 |
| aria2 | aria2/aria2 최신 릴리스 | GitHub 해시, 없으면 코드에 고정한 해시 | 하루 한 번 |
- 원본 해시와 **같을 때만** 설치한다. 해시를 구할 곳이 없거나 출처끼리 다르면 설치하지 않는다.
- 도구가 없어서 설치하는 동안 넣은 작업은 **설치가 끝나면 자동으로 시작**한다.
- 이미 있는 도구는 뒤에서 받아 두었다가 바꿔 끼운다(받는 동안에도 계속 다운로드 가능).
- ⚙ 설정 → **[지금 모두 확인·업데이트]**: 기한과 상관없이 지금 바로 확인.
- ffmpeg가 30일인 이유: 이 빌드는 매일 새로 만들어져 버전 번호(`N-127798-…-20261020`)가 매일 바뀐다. 매일 200MB를 받지 않게 했다.
- 상태는 `bin/tools.json`에 기록된다. 손으로 넣어 둔 exe도 그대로 인식한다.

## 🔗 브라우저 확장 연결
- 확장 옵션 → **[🔗 연결하기]** → 받냥이 창에 뜬 확인창에서 **[예]** → 끝.
- 공식 확장이 아니면(ID가 다르면) 경고와 함께 묻는다. 예전 방식(토큰 붙여넣기·설치 스크립트)도 그대로 된다.
- 다른 주소로 위장한 요청(DNS 리바인딩)은 받냥이가 거부한다.

## 자동 분배 (자동 모드)
- 이미지 사이트(인스타·X/트위터·네이버 블로그·Bluesky·Behance·핀터레스트·픽시브 등) → gallery-dl, 직링 파일 → aria2, 나머지 → yt-dlp.
- yt-dlp가 "지원하지 않는 주소"라고 하면 gallery-dl로 한 번 더 시도한다.
- 로그인이 필요해 보이는 오류(401·403, "Sign in")면 카드에 "[🔑 로그인]을 눌러 보세요"가 뜨고 로그인 버튼이 깜빡인다.

## 로그인 (인스타 등)
로그인이 필요한 사이트는 **🔑 로그인** 버튼을 누르면 앱 안에 로그인 창이 뜬다.
(입력칸에 URL이 있으면 그 사이트로, 없으면 인스타 로그인 페이지로 연다.)
로그인하고 **창을 닫으면** 그 세션 쿠키를 저장해 다음 다운로드부터 자동 사용한다.
- 크롬을 안 건드린다(크롬은 앱 바운드 암호화 때문에 쿠키 자동 읽기가 막힘). 앱 자체 창으로 로그인.
- 비밀번호는 저장하지 않는다. 세션 쿠키만 `cookies/cookies.txt`에 저장.
- ⚠️ 인스타는 한 번에 너무 많이 받으면 중간에 막는다(속도제한). 그럴 땐 "일부 받음"으로 뜨고,
  잠시 뒤 다시 받으면 이어서 받는다(이미 받은 건 건너뜀).

## 갤러리 보기
위쪽 **갤러리** 탭을 누르면 받은 사진·영상을 썸네일 격자로 본다. 타일을 클릭하면 폴더에서 열린다.

## 구조
- `engine.js` — URL 라우팅 + 도구 실행 + 진행률 파싱 (터미널에서도 `node engine.js <URL>` 실행 가능)
- `tools.js` / `zip.js` — 도구 자동 설치·업데이트(해시 확인) / 설치용 ZIP 풀기
- `bridge.js` — 브라우저 확장용 로컬 창구(127.0.0.1:47653, 토큰·[연결하기]·Host 검사)
- `main.js` / `preload.js` — Electron 메인 + 안전한 IPC 다리
- `index.html` / `renderer.js` / `styles.css` — 창 UI
- `tasks.json` — 작업 기록, `config.json` — 저장 폴더 설정
